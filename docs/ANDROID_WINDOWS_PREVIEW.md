# 朝夕日历：Windows 与三星手机使用说明

本版提供 Windows 电脑端和原生 Android 手机端，支持各自独立的个人日历：你在自己的电脑、手机上使用同一份同步码，朋友使用另一份。iPhone 和 Mac 不在本次交付范围内。

## 第一次使用

1. **升级电脑端。** 运行交付包中的 Windows 升级入口。升级程序会先备份旧程序及日历，再更新并打开朝夕；备份位于个人文件夹中的 `Daynote/Backups`。升级前先保存或取消正在编辑的事项。
2. **安装手机端。** 在三星手机上打开交付的 APK，按系统提示安装“朝夕日历”。“朝夕 · 测试”是独立测试应用，不用于保存正式日程。以后更新直接覆盖安装，保留尚未上传的本机修改。
3. **连接自己的日历。** 电脑端打开“账号与同步”，手机端打开右上角“设置”，分别输入自己的同步码。确认连接后，已有本机事项会加入该账号的云端日历。同步码相当于密码，请私下保存；不要把朋友的同步码填入自己的日历。
4. **检查同步状态。** 两端都打开应用并连接网络。可先新增一条“同步测试”，在另一端修改、标记完成，再删除，检查变化是否传到两端。无需连接同一个 Wi-Fi。

## 日常使用

- 手机可添加和编辑标题、备注、日期、时间、提前提醒、颜色及截止事项，也可标记完成或删除。未安排日期的事项可先保存在待办中。
- 外屏和窄窗口使用单栏；展开后的宽窗口显示月历与事项两栏。布局按窗口空间调整，编辑草稿会随折叠、旋转保留。
- 长按三星桌面 → 小组件 → 朝夕日历，可添加日程卡片，也可从应用设置中添加。拖动边框调整大小；点击事项打开，点击“＋”新建，点击刷新请求更新。
- 需要提醒时，在手机应用设置中点击“允许日程通知”，并在事项中选择提前量。全天事项以当天上午 9 点减去提前量提醒；已完成、已删除或未安排日期的事项不提醒。

## 同步时需要知道

没有网络时仍可查看和编辑，修改先保存在本机。联网后打开应用即可同步；若需要马上检查，点击“同步”。后台同步和提醒可能受三星省电设置影响，不能保证即时到达。小组件显示的是本机已保存的日程。

两端同时修改同一事项时，应用会保留本地修改的冲突副本；遇到提示后检查两份内容再整理。删除也会同步到其他设备。

断开同步不会清空本机日历；重新连接请使用原来的同步码。每份本机资料保留首次连接的账号归属，不能通过断开直接换到朋友的账号。同步失败时先查看应用中的提示，**不要通过卸载应用或清除数据来排错**，这些操作会删除尚未上传的本机内容。

手机日历不进入系统云备份，同步码由系统密钥加密保存。云端按账号隔离并使用 HTTPS 传输，但不是端到端加密。安装包不包含个人同步码或真实日程。

本页说明使用方式；设备联调、安装及提醒的实际验证结果以随包交付记录为准。
