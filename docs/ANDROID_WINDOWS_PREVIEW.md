# 朝夕日历：Android 2.6.2 与 Windows 同步使用说明

朝夕支持 Windows 电脑端和原生 Android 手机端同步：你在自己的电脑、手机上使用同一份同步码，朋友使用另一份，各自拥有独立日历。本次 2.6.2 仅更新 Android；继续使用已经安装的 Windows 同步版。更新包不含 Windows、iPhone 或 Mac 客户端。

## 第一次使用

1. **准备电脑端。** 已经安装 Windows 同步版的电脑继续使用。首次安装时，另取 Windows 升级包；其升级程序会先备份旧程序和日历，备份位于个人文件夹中的 `Daynote/Backups`。
2. **更新手机端。** 在三星手机上打开 `Daynote-2.6.2-Android.apk`，按系统提示安装“朝夕日历”。直接覆盖安装，不要先卸载或清除数据，以保留尚未上传的本机修改。“朝夕 · 测试”是独立测试应用，不用于保存正式日程。
3. **连接自己的日历。** 电脑端打开“账号与同步”，手机端打开右上角“设置”，分别输入自己的同步码。已连接的手机无需重新配对。首次确认连接后，已有本机事项会加入该账号的云端日历。同步码相当于密码，请私下保存；不要把朋友的同步码填入自己的日历。
4. **检查同步状态。** 两端都打开应用并连接网络。可先新增一条“同步测试”，在另一端修改、标记完成，再删除，检查变化是否传到两端。无需连接同一个 Wi-Fi。

## 字体和外观

在右上角“设置”中，字号分开调整：

- **应用内字号**：85%、100%、115%、130%、150% 五档，用于日历、编辑窗口和对话框。
- **小组件字号**：85%、100%、115%、130%、150%、175%、200% 七档，只调整桌面卡片。设置页有示例预览，不会展示真实日程。

两个设置互不影响，均在手机系统字号的基础上调整。升级后会先保留原来的字号选择，之后可以分别修改。字号较大时，小组件会减少显示条数；也可以在桌面上拖动边框，给它更多空间。

在“设置”的“显示与字体”区域可选择跟随系统、浅色或深色，应用和小组件共用主题。字号与主题只保存在这台手机，不上传云端，不影响电脑或其他人的设备。

## 完成和恢复事项

点击事项卡片左侧圆圈，事项会标记完成，并从日常列表和桌面小组件中消失。完成记录仍保留在“已完成”中；需要恢复时，进入“已完成”点击圆圈，或选择更多菜单中的“恢复待办”。完成和恢复状态会同步到自己的其他设备。

小组件的圆圈只执行“完成”，重复点击不会恢复事项。点击事项文字会打开编辑窗口；小组件中的已完成事项需到应用内恢复。

## 日常使用

- 手机可添加和编辑标题、备注、日期、时间、提前提醒、颜色及截止事项，也可标记完成或删除。未安排日期的事项可先保存在待办中。
- 外屏和窄窗口使用单栏；展开后的宽窗口显示月历与事项两栏。布局按窗口空间调整，编辑草稿会随折叠、旋转保留。
- 长按三星桌面 → 小组件 → 朝夕日历，可添加日程卡片，也可从应用“设置”中添加。拖动边框调整大小；随可用空间和字号显示 1–5 条近期未完成事项。较矮卡片会隐藏日期或状态行。
- 小组件中点击事项文字打开，点击圆圈完成，点击“＋”新建，点击刷新请求更新。仅用于桌面，锁屏宿主不显示日程内容，也不执行完成操作。
- 需要提醒时，在手机应用“设置”中点击“允许日程通知”，并在事项中选择提前量。全天事项以当天上午 9 点减去提前量提醒；已完成、已删除或未安排日期的事项不提醒。

## 同步时需要知道

没有网络时仍可查看和编辑，修改先保存在本机。联网后打开应用即可同步；若需要马上检查，点击“同步”。后台同步和提醒可能受三星省电设置影响，不能保证即时到达。小组件显示的是本机已保存的日程。

两端同时修改同一事项时，应用会保留本地修改的冲突副本；遇到提示后检查两份内容再整理。删除也会同步到其他设备。

断开同步不会清空本机日历；重新连接请使用原来的同步码。每份本机资料保留首次连接的账号归属，不能通过断开直接换到朋友的账号。同步失败时先查看应用中的提示，**不要通过卸载应用或清除数据来排错**，这些操作会删除尚未上传的本机内容。

手机日历不进入系统云备份，同步码由系统密钥加密保存。云端按账号隔离并使用 HTTPS 传输，但不是端到端加密。安装包不包含个人同步码或真实日程。

本页说明使用方式；设备联调、安装及提醒的实际验证结果以随包交付记录为准。
