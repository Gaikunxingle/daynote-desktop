朝夕日历
iPhone · Mac · Windows

两个人，各有自己的日历；每个人的三台设备同步同一份日程。

本包为原生客户端预览版。Windows 与 Mac 已提供编译好的程序；Apple 文件夹包含原生 SwiftUI 工程。iPhone 需在你的 Mac 上用 Xcode 和个人 Apple 账号签名安装，当前交付不包含已签名 iPhone 安装包。编译和云端测试通过不代表已在你的 iPhone/Mac 真机验证。

先准备自己的设备同步码

你和朋友各有一份不同的同步码。它相当于日历的钥匙：本人三台设备输入同一份，朋友使用朋友自己的那份。同步码单独交付，不包含在此安装包内。只把朋友那一份发给朋友，不要把自己的同步码一起发出。

第一次连接会核验账号。连接后，这份本地日历就绑定该账号，不能直接改用另一个人的同步码。断开连接会停止联网并移除本机保存的同步码，但会保留本机日程。

Windows：解压后启动

  1. 完整解压 ZIP，不要在压缩包内直接运行。
  2. 双击 启动 Windows 预览版.cmd。
  3. 预览版使用独立目录 %USERPROFILE%\Daynote\NativePreview\Data。若你原有朝夕日历数据存在，第一次启动会复制一份，原目录保持不变。以后原版与预览版是两份独立资料。
  4. 打开日历的“•••”菜单或托盘菜单，选择“账号与同步”，输入自己的同步码，按提示连接。首次上传前会保留本地备份。
  5. 朋友在自己的电脑运行同一个安装包，输入朋友自己的同步码。

不要同时在旧版和预览版编辑同一份计划：旧版的后续修改不会自动进入预览版。确认试用满意后再安排正式迁移。

Mac：使用原生应用

在 Mac 上解压 Mac/Daynote-Mac-Preview.zip，将“朝夕日历.app”放入“应用程序”。此包支持 Apple 芯片和 Intel Mac，最低 macOS 13；使用 ad-hoc 签名，尚未经 Apple 公证。如果系统不允许打开，可按下面步骤在自己的 Mac 上从源码构建，不需要关闭系统安全功能。

  1. 从 Mac App Store 安装 Xcode，启动一次并完成所需组件安装。
  2. 将解压后的 Apple 文件夹复制到 Mac。先阅读其中的安装说明。
  3. 双击 构建Mac版.command，它会运行测试并编译应用。若脚本打不开，在终端输入 bash 后把脚本拖入再回车。
  4. 也可用 Xcode 打开 Daynote.xcodeproj，选择 Daynote 和 My Mac，点击运行。
  5. 进入同步界面，输入与 Windows 相同的本人同步码。

iPhone：用你的 Mac 免费测试安装

  1. 在 Xcode 的 Settings → Accounts 中登录你自己的 Apple 账号。不需要把密码或验证码交给任何人。
  2. 用数据线连接 iPhone，按设备提示信任这台 Mac，并按苹果提示启用开发者模式。
  3. 在 Xcode 打开同一工程，在 Signing & Capabilities 选择你的 Personal Team。若应用标识已被占用，将 Bundle Identifier 改为你自己的唯一标识。
  4. 在顶部运行目标选择你的 iPhone，点击 ▶。首次安装如有信任或权限提示，由你在设备上确认。
  5. 打开朝夕，输入自己的设备同步码。需要提醒时，在 App 内开启通知，并允许系统通知权限。
免费个人签名有效期为 7 天。到期后需要重新连接 Mac，通过 Xcode 构建安装。尽量保持同一 Apple 账号和 Bundle Identifier；不要删除 App，以免丢失尚未同步的本地修改。朋友也需要在自己的 Apple 账号下完成个人测试安装。本预览版不通过 TestFlight 分发。

同步和提醒怎样工作

  • 打开应用、返回前台、修改日程以及手动同步时交换数据；应用在前台时会定期检查。
  • 断网时仍可编辑，变化留在本机，恢复联网并打开应用后继续上传。网络失败不会清空日历。
  • 两台设备同时改同一事项时，保留冲突副本供你核对。删除遇到另一台设备的新修改时会保留新版，并提示处理。
  • 有时间的日程按实际时刻同步，在设备当地时区显示；全天事项保持日历日期。
  • 每台设备独立提醒。iPhone/Mac 使用已经下载到本机的日程安排系统通知。
  • 本版不包含后台即时推送。如果在电脑新增了事项，而 iPhone 一直没有打开朝夕拉取，不能保证 iPhone 已收到新事项并安排提醒。重要日程请打开手机端确认同步状态。

先做一次简单验证

  1. 在 Windows 新增一个名为“同步试用”的虚构事项。
  2. 在 iPhone 和 Mac 打开朝夕并同步，确认出现同一事项。
  3. 在手机修改时间，再在电脑同步，确认时间变化。
  4. 在另一台设备标记完成或删除，确认各端结果一致。
  5. 朋友连接自己的同步码后，应该看不到你的“同步试用”事项。

数据与费用

客户端把日程保存在本机，联网后经 HTTPS 传到你已有的云端项目。云端按各人的同步码隔离；数据库只保存同步码的哈希，应用把同步码保存在系统凭据保护中。此设计不是端到端加密，云端项目管理员拥有维护数据的权限。

本次没有开通新的付费套餐。后续云端费用取决于已有服务的套餐、额度和用量；两个人使用并不构成永久免费的承诺。原生 iPhone 的免费测试签名与云端费用无关。
